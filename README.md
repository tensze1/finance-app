# Finance App

Finance App is a console-based application written in Java for managing personal financial transactions.
The application allows users to record income and expenses, categorize transactions, and store financial data in a CSV file.

This project was created to practice Java programming concepts, including object-oriented design and file handling.

## Features

* Add financial transactions
* Record income and expenses
* Categorize transactions
* Save transactions to a CSV file
* Load transactions from a CSV file
* View stored financial records through a console interface

## Technology Stack

* Java
* CSV file storage
* Object-Oriented Programming principles

## Project Structure

```text
finance-app

├── FinanceApp.java

├── FileService.java
└── transactions.csv
```

## Installation and Execution

1. Clone the repository:

```bash
git clone https://github.com/tensze1/finance-app.git
```

2. Navigate to the project directory:

```bash
cd finance-app
```

3. Compile the source files:

```bash
javac *.java
```

4. Run the application:

```bash
java FinanceApp
```

## Usage

The application allows users to:

* add new income or expense records
* view all stored transactions
* save financial data to a CSV file
* load transactions from the CSV file

All transaction data is stored in the `transactions.csv` file.

## Purpose of the Project

The purpose of this project is to practice:
